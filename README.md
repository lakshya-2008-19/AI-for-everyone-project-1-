# Miko Weather ⛩️ (AI for everyone mini project)

Anime-styled weather app: React + Tailwind CSS + Framer Motion + Open-Meteo (no API key).

## Run
    npm install
    npm run dev

## Deploy on Render (Static Site)
1. Push to GitHub.
2. Render -> New -> Static Site -> connect the repo.
3. Build Command: `npm install && npm run build`
4. Publish Directory: `dist`
